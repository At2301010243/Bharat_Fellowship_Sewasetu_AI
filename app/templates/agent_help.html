Using an AI assistant with Seva Setu

Seva Setu provides two secure MCP connections for compatible AI assistants. They are APIs, not web chat pages, so opening an MCP URL in a browser will show an OAuth token message.

Choose the correct connection

How it works

  1. Open your AI assistant application, not a normal browser tab.
  2. Add the appropriate MCP endpoint as a remote MCP server.
  3. The assistant discovers Seva Setu OAuth and opens the portal sign-in.
  4. Complete mobile OTP or officer login and approve the requested access.
  5. Return to the assistant. It can then call only the tools allowed for that role.

Important: successful login at Application Status or Admin does not automatically log an AI assistant in. The assistant performs its own OAuth consent flow.

OAuth discovery

  • Citizen MCP discovery
  • Officer MCP discovery
  • Authorization server metadata

This portal does not contain a built-in AI chat model. It provides the official, OAuth-protected MCP channel that an external assistant such as Claude Code or another MCP-compatible client uses.
